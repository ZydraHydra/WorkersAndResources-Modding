# Security Policy

## Reporting a Vulnerability

If you discover a security issue in this repository (for example, unsafe INI/file parsing, memory safety issues in hooks, or GitHub Actions / SteamCMD workflow secret exposure), please **do not** open a public issue.

Instead, report it privately via GitHub's **Security** tab (**Report a vulnerability** / Private Vulnerability Reporting), or contact the repository maintainer directly.

## Scope Notes

- These mods are native x64 DLL plugins injected into `SOVIET64.exe` at runtime. Only download prebuilt binaries from the official [GitHub Releases](https://github.com/ZydraHydra/WorkersAndResources-Modding/releases) or linked Steam Workshop items.
- Never share `.env.local`, SteamCMD `config.vdf` files, or Steam credentials in issues, logs, or pull requests.
