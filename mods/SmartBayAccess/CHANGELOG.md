# Changelog

## [1.0.2]
- **Shared `F9` Overlay Update:** Updated `WRSR Tweaks [F9]` overlay hub to hide in-game tweak tabs on the Main Menu until a republic is loaded and support collapsible/live-telemetry ABI extensions (for `MediaRedirector`).

## [1.0.1]

- **Steam Workshop Display Title:** Updated the Steam Workshop listing title to **WRSR Tweaks: Multi-Bay Station Entry (No Queues)** (internal DLL/INI/RML names unchanged).

## [1.0.0]

- Initial release of **SmartBayAccess** (`SmartBayAccess.dll`) with unified `F9` **Bay Access** tab.
- Supports both station/depot bay vectors (`Building + 0xB78`) and Customs House / parking bay vectors (`Building + 0xA40`).
- Includes `Vanilla` (`mode = 0`), `Same-Direction Batching` (`mode = 1`, default), and `Unrestricted` (`mode = 2`) presets with live diagnostics and `SmartBayAccess.ini` persistence.
